# 公开网站通知

1. 根据来源正文列出订阅者关心的新增或变化，再写一句可核对的触发条件。优先使用页面已经出现的条目类型和字段。样本不足时使用 [默认监控规则](defaults.json)。
2. 把逐网址提示词作为相关性标准。摘要先写本轮的实质变化，再写原文明确给出的日期、对象或下一步行动。邮件生成器负责附上来源链接。
3. 改进候选规则时，只修改摘要取舍或呈现。对照当前规则的实际通知，逐项验证改进后的摘要、原样本重复和纯空白变化。候选需保留相关更新，过滤两个反例，并给出可从样本核对的改进证据。
4. 将通过评估的候选交给组主决定是否采用。新增网址或修改监控意图由组主编辑并重新走公开审核。

## 网站组设置模板

通知 Skill 的入口元数据和预置网址在 [模板清单](../catalog.json)，共享规则在 [defaults.json](defaults.json)。新增网站 Skill 时复用这两个契约及现有网站组设置页；一个实例只管理一个网站组，监控提示词按来源保存，摘要规则和投递频率按组保存。内置研电赛保留专用赛事采集能力，并使用相同的设置导航。

试抓先建立基线，成功后由组主启用监控；手动重试保留原基线。页面须区分未配置、等待后台连接、排队、成功及失败，并展示失败原因和最近样本。通知是否相关由来源提示词决定，摘要规则只约束摘要，不改变匹配范围。
